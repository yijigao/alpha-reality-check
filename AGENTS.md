# Repository instructions

- Keep the project deterministic, local, and evidence-first.
- Never add exchange connectivity, account access, trading, market-data
  download, parameter optimization, Web services, databases, or LLM calls.
- Examples and tests must use fixed-seed synthetic data or minimal hand-written
  fixtures.
- Do not add claims of profitability, statistical certainty, adoption, or
  maturity without public evidence.
- Run the full formatting, lint, type, test, and coverage gates for every code
  change.
- Do not publish, tag, release, or merge without maintainer review.
