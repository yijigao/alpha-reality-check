# Roadmap

## v0.1 review targets

- Validate metric definitions and reference-policy semantics with reviewers.
- Stabilize the JSON schema before a first release.
- Add more adversarial fixtures for missing and misleading evidence.

## Later candidates

- Optional block-bootstrap methods for clustered trade outcomes.
- Versioned policy and report schemas.
- Additional local-file adapters that preserve the same explicit validation.
- A lightweight composite GitHub Action after CLI behavior is stable.

## Explicit non-goals

- Market-data acquisition, backtesting, alpha generation, parameter search.
- Broker or exchange connectivity and trade execution.
- Web UI, hosted SaaS, databases, user accounts, or LLM integrations.
